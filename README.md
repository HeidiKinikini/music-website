# Music Portfolio Website

## Overview
This project is a dynamic music portfolio website designed to showcase my music, visuals, and releases through a custom-built front-end experience. The site integrates with the Spotify API to automatically reflect updates to my music catalog, eliminating the need for manual content updates.

## Key Features
- Dynmaic music content powered by Spotify API
- Slide-based card interface for browsing songs
- Visual media integration (images and gallery content)
- Multi-page structure (landing page + music showcase)
- Custom front-end design and layout

## Technologies Used 
- HTML
- CSS
- JavaScript
- Spotify Web API

## Architecture & Functionality 
The application uses client-side JavaScript to retireve and display music data from Spotify. This allows the site to:
- automatically update when new songs are released
- reflect changes in song metadata without manual edits
- dynamically populate song cards within a slider-based UI

The UI is structured around a card and carousel system, where each card represents a track and includes associated visuals and metadata.

## Current State
The core structure and API integration are functional, including: 
- homepage (index)
- music showcase page
- dynamic content rendering from Spotify
- slider-based layout for browsing tracks

Some interactive components are still in progress, including:
- full button functionality for track interaction within the slider
